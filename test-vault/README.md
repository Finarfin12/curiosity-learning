# Vault uji Curiosity Learning

Folder `Fixtures` berisi 20 catatan sintetis. Enam catatan biasa, tujuh catatan Seedbed, dan tujuh topik belajar. Tes otomatis membaca fixture dan menjalankan perubahan pada salinan di memori.

1. Dari proyek, jalankan `npm run build` dan `npm run install-test-vault`.
2. Buka folder ini sebagai vault uji dan aktifkan Curiosity Learning pada pengaturan Community plugins.
3. Pilih Bahasa Indonesia di Settings. Buka **Mulai topik belajar**, isi pertanyaan “Mengapa 1/2 + 1/3 bukan 2/5?”, dugaan “1/2 + 1/3 = 2/5”, dan keyakinan 90%.
4. Buka **Diagnosis dan uji pemahaman**. Simpan penjelasan tentang pecahan senilai pada **Ajari**. Uji penjelasan sendiri di **Feynman**. Pada **Socratic**, coba petunjuk dan langkah keluar sebelum menyimpan satu jawaban.
5. Di **Uji lagi**, tulis “3/6 + 2/6 = 5/6”, pilih keyakinan, tandai jawaban benar dan dugaan awal salah. Buka **Antrean belajar** dan cek perbandingan, grafik, empat sumber bukti yang tersedia, serta satu kartu jatuh tempo.
6. Buka **Buku salah paham** untuk melihat satu kesalahan 90%. Ulas kartu tersebut dengan **Ulangi**, **Sulit**, lalu **Baik** dan cek jadwal besok di Markdown.
